# ProjecteFinal

ProjecteFinal-LGM
Desenvolupar una aplicació web modular que permeti planificar, gestionar i fer seguiment de tasques personals mitjançant formularis, visualització gràfica i persistència de dades. Aquesta aplicació simula un gestor personal d’activitats, posant en pràctica tots els coneixements apresos durant el curs.

---

Estratègia de Branques (Branching)
Per mantenir el projecte net, ordre de branques:

1.1 Main: Branca neta (el punt d'inici). 1.2 Desenvolupament: Còpia de main on aniràs fusionant tot. 1.3 feat/estructura-semantica : Després de fer el commit i provar que els enllaços funcionen, la fusiones a desenvolupament. 1.4 :Per la següent tasca, una branch feat desde el dev actualitzat.

---

Estratègia de Commits (Atomic Commits) Un commit ha de representar una sola tasca o canvi lògic.
Guia de convenció de nomenclatura: feat [localització]:(Nova funcionalitat) style [localització]: (Canvis visuals) fix [localització]: (Correcció d'errors) refactor [localització]:(Millora de codi)
